# P10 — 모델 정책·예산·개인정보 보강

명세 등록 / 제품 변경·모델 호출·시험 NOT_RUN. Refs #3. 선행 P01 #5. R1 선행 보안 gate, R2/R3 공통. REQ-01·REQ-04·REQ-05·REQ-08·REQ-09 / Core+QA / 2–4인일 추정. 기준: 개발계획 13장 및 각 생성기 경계.

## 목표와 선행성
사건·요약·전사·관계·질문·회상에 모델을 연결하기 전에 출처별 외부 처리 허용과 비용 상한을 강제한다. P07뿐 아니라 P03/P05/P08/P09/P12/P13/P14의 선택 모델 경로에 공통 적용한다. 작업 번호가 뒤라고 뒤늦게 보안을 붙이지 않는다.

## 구현 체크리스트
- [ ] 저장 허용, 외부 처리 허용, 조회 범위, 단말 복제 범위를 별도 설정으로 해석한다. 기존 인증/정책을 재사용하고 새 승인 서버를 만들지 않는다.
- [ ] 각 입력의 source policy를 합성할 때 제한을 완화하지 않는다. local-only가 포함되면 외부 경로에 해당 내용을 보내지 않는다.
- [ ] 집계·시간·중복은 규칙/SQL을 우선하고 모델 호출이 필요한 작업만 명시한다.
- [ ] provider 선택 전 scope·필드 최소화·민감도·허용 모델을 검사한다. 리랭커/임베딩/음성 전사도 모델 전송 경계에 포함한다.
- [ ] 로컬 모델 장애는 대기/실패/사실 목록 축소로 처리하고 외부 provider로 자동 우회하지 않는다.
- [ ] 일별 비용·호출·토큰·작업별 재검증 예산을 설정한다. 동시 호출에도 예산 예약/정산이 중복되지 않게 한다.
- [ ] 동일 입력 cache를 사용하되 정책/삭제/정정/모델 버전·generation과 연결하고 철회 시 재사용하지 않는다.
- [ ] 프롬프트 입력은 데이터로 격리한다. 모델 출력의 schema·근거 ID·대상·허용 관계·경로/URL을 검증한다.
- [ ] 로그/잠금 화면/Obsidian metadata/오류에 원문·정밀 좌표·건강 수치·비밀을 자동 노출하지 않는다.
- [ ] credential regex가 이메일/전화번호를 포함한 개인정보 전체 익명화가 아님을 설정 설명과 검증에 반영한다.

## 코드·정책 책임
기존 `sb/config.py`, `sb/security.py`, `sb/llm.py`와 입력 보호 함수를 대조해 보강한다. 기존 공개 계약을 변경할 때 migration/capability를 명시한다. 선언적 local_only 플래그만 추가하고 실제 전송 경로를 미검증 상태로 두지 않는다. 현 PR diff는 이 명세 문서뿐이다.

## 인수시험
AC-10: timeout/invalid citation/예산 초과에 실패 또는 축소 상태. AC-15: scope 밖 자료가 title/snippet/리랭커/임베딩/모델 request/cache에 들어가지 않음. AC-23: 악성 문서의 외부 전송·임의 도구 실행 지시 무시, 위험 Markdown/URL/외부 이미지 차단. local-only+로컬 장애에서 외부 HTTP 호출0을 spy/차단 harness로 확인한다. 결합 출처 정책·철회 직후 cache·동시 예산 예약·재시도 상한을 시험한다.

## 적용·복구·비용
설정 기본값은 가장 제한된 승인 범위이며 기존 서비스가 제공하던 허용 경로와 호환성을 시험한다. 가격/월비용을 기억에서 고정하지 않고 선택 모델 당시 가격과 사용량으로 측정한다. 정책 변경 실패는 permissive fallback이 아니라 거부/대기다. 모델 기능 OFF도 정정/철회를 멈추지 않는다.

## 완료 증거
출처별 policy matrix, egress 차단 증거, 실제 요청 redacted metadata, 예산 경합 로그, cache 철회 시험, pytest/Ruff·독립 검토가 필요하다. 현재 모든 제품 구현/검증 NOT_RUN. 이 명세 PR 생성은 외부 AI에 개인 데이터를 보낼 권한을 새로 부여하지 않는다.
